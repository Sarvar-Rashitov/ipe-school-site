# Create a Premium Educational Center Website  Build a modern, premium, conversion-focused educational center website using Next.js 15, TypeScript, Tailwind CSS, Shadcn UI, Framer Motion and Lucide React Icons.  The website must feel like a combination of a modern SaaS landing page and a premium educational brand.  The primary goal is:  \* Increase course registrations \* Generate leads \* Increase phone calls \* Increase Telegram inquiries \* Build trust through social proof  Every section should encourage users to take action.  ---  ## Design Style  Create a modern and premium UI.  Avoid generic educational website designs.  Inspiration:  \* Modern SaaS products \* Apple-level cleanliness \* Stripe-level spacing \* Linear-style minimalism  Requirements:  \* Large typography \* Plenty of whitespace \* Modern cards \* Soft shadows \* Subtle gradients \* Glassmorphism only where appropriate \* Consistent border radius \* Premium micro interactions \* Modern hover effects \* Smooth animations  Use Lucide React icons only.  Do not use emoji or unicode icons.  ---  ## Tech Stack  \* Next.js 15 App Router \* TypeScript \* Tailwind CSS \* Shadcn UI \* Framer Motion \* React Hook Form \* Zod \* Server Actions \* Telegram Bot API  ---  # Pages  ## Home Page  ### Hero Section  Support both:  \* Hero Video \* Hero Image Fallback  Logic:  If a video exists, use video background.  Otherwise use hero image.  Hero content:  \* Powerful headline \* Short description \* Primary CTA \* Secondary CTA  Include floating statistics:  \* Students \* Teachers \* Courses \* Success Rate  Create a visually impressive hero section.  Not a basic centered layout.  Use modern asymmetric composition.  ---  ## Trusted By Section  Display:  \* Partner logos \* University logos \* Company logos  Responsive logo carousel.  ---  ## Why Choose Us  Modern feature cards.  Each card:  \* Lucide icon \* Title \* Description  Use a premium grid layout.  ---  ## Courses  Display course cards.  Each card:  \* Cover image \* Course title \* Short description \* Duration \* Learn More \* Register Free Lesson  Card hover animations should feel premium.  ---  ## Teachers  Premium team section.  Each teacher card:  \* Photo \* Name \* Position \* Experience \* Social links  Modern card design.  ---  ## Student Results  Display:  \* IELTS results \* CEFR results \* University admissions \* Job placements  Use image gallery and achievement cards.  ---  ## Testimonials  Support:  \* Video testimonials \* YouTube Shorts embeds \* Instagram Reels embeds  Display testimonials in a modern carousel.  ---  ## Gallery  Modern masonry layout.  Categories:  \* Campus \* Classes \* Events \* Students  Lightbox support.  ---  ## FAQ  Animated accordion.  ---  ## CTA Banner  Large conversion section.  Strong headline.  Clear CTA button.  ---  # Contact Page  Create a beautiful contact experience.  Fields:  \* Full Name \* Phone Number \* Message  Submission should send data directly to Telegram Bot.  Use:  \* Loading state \* Success state \* Error state  Display elegant toast notifications.  ---  # Free Lesson Registration  Create a dedicated modal.  Fields:  \* Full Name \* Phone Number \* Selected Course  When opened from a course page, course should be preselected automatically.  Send submission to Telegram.  ---  # Telegram Integration  Create reusable Telegram utility.  Environment variables:  TELEGRAM\_BOT\_TOKEN  TELEGRAM\_CHAT\_ID  Create:  lib/telegram.ts  Use Server Actions.  Handle:  \* Validation \* Errors \* Rate limiting \* Loading states  ---  # Navigation  Modern sticky navbar.  Include:  \* Logo \* Home \* Courses \* Teachers \* Results \* Gallery \* Contact  Mobile menu must be elegant and smooth.  ---  # Floating Actions  Fixed position actions:  \* Telegram \* Call \* Free Registration  Visible on mobile and desktop.  ---  # Footer  Do NOT create a traditional footer.  Design a premium footer experience.  Include:  \* Brand section \* Quick links \* Courses \* Contact information \* Social media  Socials:  \* YouTube \* Instagram \* Telegram \* LinkedIn  Add subtle animations.  Use layered layout.  Make footer memorable.  ---  # Media Folder Structure  public/  images/ ├── hero/ ├── courses/ ├── teachers/ ├── students/ ├── gallery/ ├── logos/ ├── testimonials/ ├── partners/  videos/ └── hero/  ---  # Animations  Use Framer Motion.  Implement:  \* Fade Up \* Stagger Cards \* Reveal On Scroll \* Smooth Hover Effects \* Number Counter Animations  Animations must feel premium and professional.  Avoid excessive motion.  ---  # SEO  Implement:  \* Metadata API \* Open Graph \* Twitter Cards \* Structured Data \* Sitemap \* Robots.txt  ---  # Accessibility  \* Keyboard navigation \* Focus states \* Proper ARIA labels \* Semantic HTML  ---  # Performance  \* Server Components \* Image Optimization \* Lazy Loading \* Dynamic Imports \* Optimized Video Loading  Target Lighthouse Score:  95+  ---  # Code Quality  Architecture must be:  \* Scalable \* Modular \* Reusable \* Production-ready  Generate clean folder structure, reusable components, and maintainable code.
